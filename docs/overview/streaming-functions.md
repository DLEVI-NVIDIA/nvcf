# Low Latency Streaming (LLS/WebRTC) Functions

For the Low Latency Streaming (LLS) architecture, see
[Request and Streaming Flow](https://docs.omniverse.nvidia.com/ovs/latest/low-latency-streaming/lls-deployment.html#request-and-streaming-flow).

## Cloud Provider Network Requirements

See the [LLS load balancer requirements](https://docs.omniverse.nvidia.com/ovs/latest/low-latency-streaming/lls-deployment.html#step-2-create-network-load-balancer).
For service installation, start with the [LLS deployment prerequisites](https://docs.omniverse.nvidia.com/ovs/latest/low-latency-streaming/lls-deployment.html#prerequisites).

## Creating the LLS Streaming Function

For Omniverse Kit applications, follow
[Create Streaming Function](https://docs.omniverse.nvidia.com/ovs/latest/kit-guide/deploying.html#create-streaming-function)
and [Deploy Streaming Function](https://docs.omniverse.nvidia.com/ovs/latest/kit-guide/deploying.html#deploy-streaming-function).

## Connecting to a streaming function with a client

Use the [NVCF web client sample](https://docs.omniverse.nvidia.com/ov-web-sdk/latest/web-sample/overview.html#nvcf-sample).

### Intermediary Proxy

For the web client and its intermediary proxy, see the
[NVCF sample configuration](https://docs.omniverse.nvidia.com/ovs/latest/kit-guide/web-streaming-client.html#available-sample-configurations).
