# LLS Installation

For Low Latency Streaming (LLS) installation, start with the
[deployment prerequisites](https://docs.omniverse.nvidia.com/ovs/latest/low-latency-streaming/lls-deployment.html#prerequisites)
and follow the installation steps in that guide.

After installation, follow
[Verify Deployment](https://docs.omniverse.nvidia.com/ovs/latest/low-latency-streaming/lls-deployment.html#step-5-verify-deployment).
